---
id: SBML-0001
rule: "When the model's language is SBML, a label on its '.model' output must be the SId of an element in the model's SId namespace that has a numerical value."
message: "{class} '{id}' references '{value}', but the SBML model has no element with the id '{label}' that has a numerical value."
severity: error
status: proposed
check: handwritten
---

Checked by a format-aware library only.  Without one, validation assumes the
label is potentially valid.  Elements with a numerical value include species,
compartments, global parameters and reactions (see labels.md).
