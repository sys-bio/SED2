---
id: SBML-0002
rule: "When the model's language is SBML, a label on its '.model' output must not name a reaction's local parameter."
message: "{class} '{id}' references '{value}', but '{label}' is a local parameter of a reaction, which is not in the model's SId namespace."
severity: error
status: proposed
check: handwritten
---

Local parameters are scoped to their reaction (see labels.md), so a bare
label cannot refer to them unambiguously.  This applies even when a local
parameter happens to share its id with a global element: the label then names
the global element, and this rule does not fire.
