---
id: AbstractOutput-0001
rule: The outputParameters attribute of an AbstractOutput must be an array of OutputParameter objects.
message: "Attribute '{attr}' of {class} '{id}' has value '{value}', which is not an array of OutputParameter objects."
severity: error
status: active
---

`outputParameters` is `array of OutputParameter` in AbstractOutputCommon: it must be an array of OutputParameter objects.
