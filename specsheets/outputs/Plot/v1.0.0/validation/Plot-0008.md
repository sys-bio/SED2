---
id: Plot-0008
rule: When the value of yAxis of a Plot is a reference, it must be a reference to a valid one of `"right"`, `"left"` value.
message: "Attribute '{attr}' of {class} '{id}' is the reference '{value}', which resolves to '{resolved-value}', not a valid one of `"right"`, `"left"` value."
severity: error
status: active
check: ref-type
---

`yAxis` is `one of `"right"`, `"left"` or SIdRef` in Plot: when the value is a reference, it must resolve to a valid one of `"right"`, `"left"` value.
