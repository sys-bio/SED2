---
id: Plot-0002
rule: When the value of legend of a Plot is a reference, it must be a reference to a boolean.
message: "Attribute '{attr}' of {class} '{id}' is the reference '{value}', which resolves to '{resolved-value}', not a boolean."
severity: error
status: active
---

`legend` is `BooleanOrRef` in Plot: when the value is a reference, it must resolve to a boolean.
