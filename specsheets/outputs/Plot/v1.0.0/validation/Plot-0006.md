---
id: Plot-0006
rule: When the value of width of a Plot is a reference, it must be a reference to a number.
message: "Attribute '{attr}' of {class} '{id}' is the reference '{value}', which resolves to '{resolved-value}', not a number."
severity: error
status: active
check: ref-type
---

`width` is `NumberOrRef` in Plot: when the value is a reference, it must resolve to a number.
