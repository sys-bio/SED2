---
id: Plot2D-0004
rule: The _type attribute of a Plot2D must be "plot2D".
message: "Attribute '{attr}' of {class} '{id}' has value '{value}', which does not match the required value '{allowed}'."
severity: error
status: active
---

`_type` is the discriminator field. For `Plot2D` it must always equal `"plot2D"`.
