---
id: Plot2D-0002
rule: The curves attribute of a Plot2D must be an object whose values are Curve.
message: "Attribute '{attr}' of {class} '{id}' has value '{value}', which is not an object whose values are Curve."
severity: error
status: active
check: schema
---

`curves` is `object (values: Curve)`: it must be an object whose values are Curve.
