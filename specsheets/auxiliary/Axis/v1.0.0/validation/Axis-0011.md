---
id: Axis-0011
rule: When the value of reverse of an Axis is a reference, it must be a reference to a boolean.
message: "Attribute '{attr}' of {class} '{id}' is the reference '{value}', which resolves to '{resolved-value}', not a boolean."
severity: error
status: active
check: ref-type
---

`reverse` is `BooleanOrRef`: when the value is a reference, it must resolve to a boolean.
