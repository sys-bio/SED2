---
id: Axis-0004
rule: When the value of min of an Axis is a reference, it must be a reference to a number.
message: "Attribute '{attr}' of {class} '{id}' is the reference '{value}', which resolves to '{resolved-value}', not a number."
severity: error
status: active
---

`min` is `NumberOrRef`: when the value is a reference, it must resolve to a number.
