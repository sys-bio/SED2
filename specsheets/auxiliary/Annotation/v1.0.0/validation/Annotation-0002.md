rule: The qualifier attribute of an Annotation must be a Qualifier string (a 'namespace:term' pair).
message: "Attribute '{attr}' of {class} '{id}' has value '{value}', which is not a Qualifier string (a 'namespace:term' pair)."
severity: error
status: active
---

`qualifier` is `Qualifier`: it must be a Qualifier string (a 'namespace:term' pair).
