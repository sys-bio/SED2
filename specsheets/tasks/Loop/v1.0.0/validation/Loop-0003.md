---
id: Loop-0003
rule: The loopVariables attribute of a Loop must be an object whose values are LoopVariable.
message: "Attribute '{attr}' of {class} '{id}' has value '{value}', which is not an object whose values are LoopVariable."
severity: error
status: active
---

`loopVariables` is `object (values: LoopVariable)`: it must be an object whose values are LoopVariable.
